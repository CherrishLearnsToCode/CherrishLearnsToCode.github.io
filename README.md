# 💗 Apology Microsite

A beautiful, interactive apology website with a cherry pink theme, built with love.

## 🌸 Features

- **Cherry pink gradient background** with glassmorphism design
- **Interactive step-by-step revelation** of heartfelt messages
- **Personal photos** that appear with each step
- **Movie selection** for tonight's date
- **Confetti animation** for the final reveal
- **Mobile-friendly** responsive design
- **Accessibility features** with ARIA support

## 🎬 Movie Options

- 🧱 **Brick** - Neo-noir mystery
- 📞 **The Guilty** - Intense thriller
- 🎬 **Your Choice** - Whatever you want to watch
